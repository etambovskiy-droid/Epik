# Скасування змін дизайну: повернення до робочого столу PIM Workbench

Зміни, внесені за попереднім запитом щодо відтворення еталонного скріна (темна Mono-палітра з фіксованим баром та віджетом «СТАТУС PIM-ФІДУ»), успішно скасовано відповідно до вказівки.

---

## 1. Скасовані елементи
- [x] **Нижня скляна панель навігації (`EpicentrBottomNav`)**: повністю вилучена з коду та інтерфейсу, усунено зайвий нижній відступ сторінки.
- [x] **Віджет «СТАТУС PIM-ФІДУ» (`EpicentrDashboardOverview`)**: вилучено фіксовану картку на 9 товарів, сітку швидких дій та блок останніх операцій.
- [x] **Видалено застарілі файли**:
  - `src/components/epicentr/EpicentrDashboardOverview.tsx`
  - `src/components/epicentr/EpicentrBottomNav.tsx`
  - `src/design-backup-info.json`

---

## 2. Відновлений стан робочого середовища
- [x] **Прямий доступ до PIM Workbench**: робочий стіл одразу відкриває завантаження шаблону Excel, довідників категорій, фотографій та XML-файлів.
- [x] **Верхня панель навігації (`EpicentrNavbar`)**:
  - Логотип «Епіцентр Маркетплейс» та індикатор поточної версії.
  - Перемикач робочих кабінетів селера (TechSmart та інші).
  - Швидкі дії: «XML-фід», «Валідатор назв», «Регламент», «Історія».
  - Індикатор фонового автозбереження чернетки.
  - Повноцінний перемикач теми (Світла / Темна / Системна) та мови (UA / EN).
  - Аватар авторизованого селера з випадаючим drawer-меню налаштувань / кнопка входу.
- [x] **Модуль авторизації та налаштувань (збережено)**:
  - Авторизація через AuthModal.
  - Слайд-овер панель профілю продавця (UserProfileDrawer) з редагуванням реквізитів, Bearer-токена та зміною пароля.
  - Збереження сесії користувача та налаштувань у `localStorage`.
