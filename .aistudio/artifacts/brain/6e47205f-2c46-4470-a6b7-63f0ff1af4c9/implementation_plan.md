# Діагностика та усунення проблем із заповненням та вивантаженням шаблону

## 1. Чому перший етап (Експрес) візуально показував 0 заповнених полів агентом:
- **Корінь проблеми**: У `src/App.tsx` в обробнику `handleUpdateRowValues` при відсутності посилань Google Search Grounding (`sources`) усім заповненим значенням привласнювався статус `source: 'already_filled'`.
- **Наслідок**: 
  - Значення фактично підставлялися в таблицю (як видно на скріншоті: *"Очищення; Живлення; Зволоження"*, *"86"*, *"86"*, *"МАС-маркет"*), але маркувалися як "Оригінальне значення" (блакитна крапка) замість "Заповнено агентом з довідника" (зелена крапка).
  - Фільтр-бейдж "Заповнені агентом (0)" шукав виключно поля з `source !== 'already_filled'`, тому показував 0.
- **Виправлення**: Для Експрес-етапу, PIM-аналізу та кешу серій встановлено валідні джерела `source: 'local_express'`, `'series_cache'`, `'description'`, а для ручних дій — `'manual'`. Лічильник тепер коректно відображає кількість оброблених товарів.

---

## 2. Чому шаблон вивантажувався в Excel порожнім без характеристик:
- **Корінь проблеми 1 (Невідповідність ключів колонок)**: У функції `generateEpicentrExportWorkbook` (`src/services/epicentrEngine.ts`) пошук значення проводився виключно за точним рядком `col.originalName` через `hasOwnProperty`. Якщо колонка містила перенесення рядків (наприклад, `Призначення *\n[ua]`), а оновлені значення зберігалися за нормалізованим ім'ям `col.cleanName`, кандидат повертав порожній рядок.
- **Корінь проблеми 2 (Агресивне очищення при відсутності файлу довідника)**: Якщо користувач завантажив на Vercel тільки шаблон товарів без окремого файлу `Довідник_...xlsx`, об'єкт `dictionaryIndex` був порожнім. Для колонок типів `select` та `multiselect` рушій експорту за відсутності `dictAttr` безумовно повертав `''`, повністю стираючи всі заповнені характеристики з вихідного файлу!
- **Виправлення**: 
  - Реалізовано каскадний пошук значення кандидата: `col.originalName` -> `col.cleanName` -> `normalizeEpicentrHeaderName` -> `pRow.diffs`.
  - Якщо для колонки немає завантаженого довідника, валідне заповнене значення (не є hex-кодом чи системним текстом) зберігається та потрапляє у вивантажений Excel.

---

## 3. Чому після заповнення плашка залишалася "Порожні обов'язкові (50)":
- **Аналіз категорії**: У категорії косметики та догляду за обличчям наявні **22 обов'язкові колонки** зі зірочкою `*` (зокрема: *Клас косметики, Призначення, Висота упаковки, Глибина упаковки, Ширина упаковки, Країна реєстрації бренду, Країна-виробник, Об'єм/Вага, Склад, Тип шкіри, Спосіб застосування* тощо).
- Якщо хоча б 1 із 22 полів залишається порожнім, товар потрапляє до фільтра "Порожні обов'язкові".
- На скріншоті видно, що 4 видимі колонки заповнилися, а статус `Порожні обов'язкові (50)` сигналізує про решту обов'язкових полів, інформація про які була відсутня в тексті або не знайдена у веб-пошуку.
